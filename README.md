# База знаний — SQL и PostgreSQL

Минималистичный тренажёр по всем 119 вопросам из «Бд тест2.pdf».

- **По одному:** страница без прокрутки; radio показывает результат сразу, checkbox проверяется кнопкой.
- **Все ответы:** все вопросы на одной странице, поиск, пояснения и источники.
- Сопоставления, навигация по вопросам и сохранение прогресса в браузере.
- Ответы проверяются по документации; исходная статистика голосования сохранена отдельно.

## На телефоне

Крупные элементы управления, учёт безопасных зон экрана и горизонтальной ориентации. Текст не уменьшается для вмещения: длинный вопрос делится на части с кнопкой «Продолжить». Выбранные варианты сохраняются между частями; после проверки сразу виден результат. Страница практики не прокручивается.

Проверено в браузерных размерах 320×568, 390×844 и 844×390; физические iPhone/Android не тестировались.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не нужны. Для стабильного сохранения прогресса можно запустить локальный сервер:

```sh
python -m http.server 8080
```

Затем откройте `http://localhost:8080`. Файлы готовы для любого статического хостинга, в том числе GitHub Pages (ветка `main`, папка `/root`). Публикация Pages настраивается отдельно в Settings → Pages.

## Перепроверка ответов

Полный отчёт по каждому из 119 вопросов: [ANSWER_AUDIT.md](ANSWER_AUDIT.md).

Повторный аудит выполнен 13 ноября 2026 года. Сначала проверены все выбранные и отклонённые варианты, затем спорные исполнимые примеры проверены в отдельной PostgreSQL 18.4. Источники указаны непосредственно в каждом вопросе. Общие определения проверены по первичным учебным и исследовательским источникам.

В №13, 29, 38, 45, 67 и 90 уточнены формулировки или варианты. В заданиях с флажками каждый засчитываемый набор содержит минимум два ответа. №75 не имеет корректного варианта в PostgreSQL и не влияет на оценку. Для нескольких действительно неоднозначных вопросов допускаются явно перечисленные наборы ответов; пояснение доступно в разборе. Эти наборы — результат проверки, а не официальный ключ преподавателя.

```sh
node verify.mjs
```

SQL-проверки запускайте **только в отдельной тестовой базе PostgreSQL 18** с доступным расширением `tablefunc`:

```sh
psql -v ON_ERROR_STOP=1 -d YOUR_TEST_DATABASE -f verification.sql
```

Скрипт создаёт собственную схему и завершает работу `ROLLBACK`; существующие прикладные таблицы не использует.

- `questions.js` — вопросы, голоса, проверенные ключи, источники и сведения об аудите.
